# Newton ágyúgolyója · Newton's Cannonball

Interactive physics web app for high-school classrooms (Hungarian / English). See [PLAN.md](PLAN.md) for the full design.

```bash
npm install
npm run dev      # local development server
npm test         # physics verification suite (see docs/VALIDATION.md)
npm run build    # → dist/index.html, a single file that works offline
```
